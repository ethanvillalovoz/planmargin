# Local screen-recording walkthrough

The Version 2.1 sign-off includes a real 16-second recording of the public
aggregate Evidence workflow. The retained copy contains no generated imagery,
mock UI, or synthetic runtime data.

The recording is deliberately local and ignored:

```text
artifacts/demo/planmargin-v2.1-evidence-tour.mov
```

It is 1064×594 H.264 at 60 fps. Browser chrome was cropped from the retained
file, so the video contains no tab titles, address bar, or ephemeral local
credential. Three sampled frames were inspected after encoding.

This artifact is not hosted, committed, or bundled with the aggregate evidence
package. Publishing a demo remains a separate decision because licensed
Workbench media and public aggregate evidence have different redistribution
boundaries. A future public recording should stay entirely on the aggregate
Evidence surface unless every visible local artifact has been cleared for
redistribution.
